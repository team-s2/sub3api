# OneBot 机器人

内置聊天机器人，由 NapCat 等 OneBot 11 实现通过反向 WebSocket 连入。功能对应 `astrbot_plugin_newapi` 和 `pigapi/internal/bot`：这两者的渠道、订阅在这里是上游账号。

## 配置

```yaml
onebot:
  enabled: true
  path: /onebot/v11/ws        # 默认值
  self_id: "123456"           # 机器人 QQ 号，校验 X-Self-ID 和 get_login_info
  token: "<secret>"           # 校验 Authorization: Bearer
  command_prefix: sub3api     # 默认值，命令形如 /sub3api quota
  allowed_groups: ["100"]     # 群内所有成员可执行命令
  allowed_users: ["200"]      # 私聊白名单
```

环境变量同样可用：`ONEBOT_ENABLED`、`ONEBOT_SELF_ID`、`ONEBOT_TOKEN`、`ONEBOT_ALLOWED_GROUPS=100,101` 等。名单留空时拒绝所有会话。

服务只接受一个连接，多副本部署时 NapCat 只会连到其中一个 Pod。

## 命令

发送 `/sub3api` 查看完整帮助：`quota`、`flow`、`status`、`on/off`、`priority`、`weight`、`limit`、`mv`、`rm`、`oauth`。

- `quota` 和 `flow` 的图片由 `internal/render` 绘制，移植自 pigapi，依赖镜像内的 `font-noto-cjk`。绘图失败时 `quota` 退回文字。
- `rm` 不支持 `all`，避免一条消息删光账号。
- `oauth` 只新建 Codex 账号；回调 URL 需由发起者在同一会话内发送，10 分钟内有效。

## 未移植

pigapi 的 `org`、`share`、`auth`、`session`、`reserve`、`fp`、`import` 依赖其租户模型和 Codex 会话亲和，sub2api 没有对应概念。
